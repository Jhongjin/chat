# Mobile Chat Design Strategy

기준일: 2026-06-03.

## 방향

DongneOn의 채팅 화면은 메신저처럼 빠르되, 소개팅 앱처럼 과열되지 않아야 한다. 디자인의 중심은 장식이 아니라 `대화 맥락`, `안전 통제`, `가벼운 첫 인사`, `방해 없는 리워드`다.

Google Stitch의 DESIGN.md 흐름처럼 디자인 원칙을 코드와 같은 저장소에 두고, AI/개발자/디자이너가 같은 기준을 읽도록 유지한다. Stitch skills의 목적은 반복 가능한 제작 규칙을 만드는 것이므로, 앱의 각 화면도 기능 목록이 아니라 사용자가 느끼는 상태와 행동으로 정의한다.

## 채팅 전용 UI 원칙

- 헤더는 이름만 보여주지 않고 `대략 동네`, `대략 거리`, `마지막 활동`, `응답 성향`, `인증/안전 상태`를 작은 단서로 제공한다.
- 말풍선은 장식보다 가독성을 우선한다. 메시지 시간은 말풍선 아래에 붙여 대화의 흐름을 놓치지 않게 한다.
- 신고, 숨김, 차단은 헤더와 개별 메시지 양쪽에서 접근 가능해야 한다.
- 빠른 답장은 첫 대화 부담을 낮추되, 스팸처럼 보이지 않도록 2-3개 칩으로 제한한다.
- 입력창 주변 안전 문구는 낮은 대비로 둔다. 사용자를 겁주기보다 정확한 주소와 연락처 공유를 천천히 하게 만드는 넛지로 작동해야 한다.
- 연락처, 상세 주소, 외부 메신저 ID가 입력되면 전송 후 차단보다 입력 중 안내를 먼저 보여준다.
- 광고와 리워드 CTA는 채팅방 안에 직접 삽입하지 않는다. 대화 신뢰가 수익화보다 먼저다.
- 화면에는 `Supabase`, `AdMob`, `데모`, `검수용` 같은 개발/운영 언어를 노출하지 않는다. 필요하면 내부 상태 메시지를 사용자 언어로 변환한다.
- 사람을 `추천 82%`처럼 점수화하지 않는다. 추천 이유는 `공통 관심사 2개`, `응답 빠른 편`, `방금 활동`처럼 설명형 신뢰 칩으로 보여준다.
- 재방문 사용자는 같은 온보딩을 반복하지 않게 한다. 최소 프로필과 동의 상태는 로컬에 복원하되, 민감한 정보는 늘리지 않는다.
- 관심사, 탐색 필터, 반경, 노출/숨김 상태도 재방문 맥락이다. 백엔드 동기화 전에도 마지막 선택을 로컬에서 복원한다.
- 계정 삭제 요청이 접수되면 편의용 로컬 복원 데이터보다 프라이버시가 우선이다. 온보딩 프로필과 대화 관련 로컬 흔적을 제거한다.
- 채팅 입력 초안은 대화방별로 분리한다. 사용자가 방을 오가도 작성 중인 문장이 엉뚱한 상대에게 보이지 않아야 한다.

## 이번 큐 반영

- 채팅방 헤더에 마지막 활동 정보를 추가했다.
- 헤더 아래에 가로 컨텍스트 레일을 추가해 동네, 거리, 응답 성향, 안전 상태를 한 번 더 보여준다.
- 메시지 말풍선 아래에 전송 시간을 표시한다.
- 입력창 위에 연락처와 정확한 주소 공유를 늦추는 안전 넛지를 추가했다.
- 발견 화면의 점수 막대를 설명형 신뢰 칩으로 바꿨다.
- 앱 상태 밴드와 리워드 화면에서 개발/광고 플랫폼명을 사용자 언어로 감쌌다.
- 채팅 입력창이 하단 탭과 겹치지 않도록 하단 탭을 절대 배치에서 일반 레이아웃으로 바꿨다.
- 메시지 리스트를 남은 공간 안에서 스크롤되게 고정해 빠른 답장과 입력창이 화면 아래에 유지되도록 했다.
- 열린 대화방에서는 동기화 밴드와 검색창을 숨겨 대화 헤더, 메시지, 입력창이 화면의 주인공이 되게 했다.
- 컨텍스트 레일과 빠른 답장 레일의 높이를 고정해 남는 세로 공간을 칩이 과하게 차지하지 않도록 했다.
- 대화방 진입과 메시지 추가 시 최신 메시지로 자동 이동하고, 메시지가 적을 때도 입력창 위에 붙도록 리스트를 하단 정렬했다.
- 온보딩 완료 프로필을 로컬에 저장해 앱 재시작 후에도 바로 동네/쪽지 화면으로 이어지게 했다.
- 탐색 반경, 현재 필터, 관심사, 추천 노출, 동네 숨김 상태를 로컬 저장/복원하도록 했다.
- 채팅 입력창과 첫 쪽지 모달에 민감 정보 입력 중 경고 상태를 추가하고, 해당 상태에서는 전송 버튼을 비활성화했다.
- 계정 삭제 요청 성공 시 로컬 온보딩 프로필, 즐겨찾기, 숨김 메시지, 차단 목록 저장값을 제거하도록 했다.
- 대화방별 입력 초안을 분리하고 전송, 숨김, 차단, 계정 삭제 시 관련 초안만 정리하도록 했다.

## 다음 디자인 큐

- 캐릭터 `온이`의 3가지 상태를 확정한다: 위치 권한, 빈 대화, 안전 안내.
- iOS/Android 실기기에서 하단 탭, 입력창, 키보드 회피, 안전 모달 터치 범위를 점검한다.
- Discover 카드의 정보 밀도를 한 번 더 줄이고, 추천 이유와 첫 쪽지 CTA를 더 명확히 분리한다.
- 리워드 화면은 광고 보상보다 사용자가 얻는 편익을 먼저 읽게 카드 계층을 재정리한다.
- 모션은 리스트 등장 120-180ms, 화면 전환 220-280ms 기준으로 일관화한다.
