# 채팅 경험 고도화 로드맵

기준일: 2026-05-30.

## 이번 MVP에 반영한 기능

- 관심사 필터: `전체`, `카페`, `산책`, `러닝`, `맛집`, `책` 기준으로 근처 친구를 빠르게 좁힌다.
- 추천 설명: 공통 관심사, 거리, 최근 활동, 응답률을 조합한 추천 점수와 이유를 리스트에서 바로 보여준다.
- 첫 쪽지 템플릿: 상대 관심사와 동네를 활용한 부담 낮은 첫 인사 템플릿을 제공한다.
- 쪽지 일일 제한: 기본 하루 3회, 리워드로 추가 쪽지권을 받을 수 있는 구조를 둔다.
- 안전 넛지: 전화번호, 주소, 외부 메신저 ID가 포함된 첫 쪽지/초기 메시지는 제한하고, 첫 쪽지 작성 화면에서 앱 안 대화를 안내한다.
- 빠른 답장: 채팅방 하단에 맥락형 짧은 답장을 제공해 대화 시작 부담을 줄인다.
- 리워드 상한: 리워드 광고 보상은 하루 3회까지만 지급하는 UI 상태를 둔다.

## 다음 구현 우선순위

1. 쪽지 요청 수락/거절

현재는 Supabase `message_requests`, 수락/거절, `conversations`, 메시지 전송 RPC까지 연결되어 있다. 다음 단계는 운영 환경에서 Realtime 이벤트, 푸시 알림 큐, 신고 검수 콘솔을 붙이는 것이다.

2. 신뢰 레벨

휴대폰/Apple/Google 인증, 신고 이력, 답장률, 차단율을 조합해 내부 신뢰 레벨을 계산한다. UI에는 과한 점수 대신 `확인됨`, `응답이 빠른 편`, `새로 온 이웃` 정도로 부드럽게 표시한다.

3. 대화 품질 보호

반복 문구, 연락처 유도, 짧은 도배 메시지, 신고 누적 문구를 서버에서 제한한다. 차단/신고가 많은 계정은 리워드 부스트와 추가 쪽지권 사용을 제한한다.

4. 사용자 편의

- 조용한 시간 알림 끄기
- 대화 즐겨찾기
- 관심사 기반 추천 질문
- 내 동네 일시 숨김
- 차단 목록 관리
- 계정 삭제와 데이터 다운로드 요청

5. 수익화 실험

리워드 광고는 추가 쪽지권, 추천 새로고침, 짧은 부스트에만 연결한다. 채팅 중간 광고와 강제 전면 광고는 금지한다. 추후 IAP는 광고 제거, 고급 필터, 추가 쪽지권 묶음으로 제한한다.
