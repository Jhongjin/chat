# DongneOn 제품 전략

## 제품 한 문장

5km 안의 동네 사람과 부담 없이 시작하는 안전한 친구 쪽지 앱.

## 차별화 원칙

1. 정확한 위치가 아닌 안심 거리

서버는 거리 계산을 위해 좌표를 쓰되, 사용자에게는 정확한 좌표나 주소를 보여주지 않는다. UI는 `OO동 근처`, `500m 이내`, `약 2km`, `3km대`처럼 대략 정보만 표시한다.

2. 무한 스와이프 대신 제한된 쪽지

하루 무료 첫 쪽지 수를 제한하고 상대가 수락해야 채팅방이 열린다. 리워드 광고로 쪽지권을 추가할 수 있지만 일일 상한을 둬서 스팸을 막는다.

3. 친구 목적을 전면에

초기 포지션은 연애/소개팅이 아니라 동네 수다, 취미, 산책, 카페, 생활 정보다. 데이팅 니즈를 완전히 막지는 않되 UI와 카피는 낮은 압력의 대화로 설계한다.

4. 검증과 개인정보 최소 수집의 분리

프로필에는 이름, 나이, 성별, 동네 정도만 보인다. 내부적으로는 휴대폰 인증, Apple/Google 로그인, 기기 중복 방지, 신고/차단 이력을 통해 안전을 확보한다.

## MVP 범위

| 영역 | 포함 기능 |
| --- | --- |
| 온보딩 | 이름/닉네임, 나이, 성별, 18세 이상 확인, 약관/개인정보/위치 동의, 위치 권한 요청과 거부 fallback |
| 탐색 | 5km 내 친구 리스트, 반경 1-5km 조절, 관심사 태그, 대략 거리 |
| 쪽지 | 하루 기본 쪽지권, 수락/거절, 차단/신고 |
| 채팅 | 텍스트, 읽음 상태, 푸시 알림, 대화 목록 |
| 안전 | 신고 큐, 차단, 운영자 정지, 금칙어/스팸 필터, 계정 삭제 |
| 수익화 | AdMob 리워드 광고로 추가 쪽지권, 추천 새로고침, 프로필 부스트 |
| 분석 | 가입 전환, 위치 허용률, 쪽지 발송률, 수락률, 첫 답장률, 신고율, D1/D7 |

## 초기 출시 전략

- 서울/수도권 특정 구 단위로 작은 지역 밀도를 먼저 만든다.
- 초기 사용자 풀은 친구 초대, 지역 커뮤니티, 대학가/직장가 타깃으로 확보한다.
- 신규 유저에게 빈 화면을 보여주지 않도록 운영 계정/검수된 초기 프로필/추천 질문을 준비한다.
- 매칭 수보다 신고율, 답장률, 대화 지속률을 더 중요한 지표로 둔다.

## 수익화 전략

광고는 기본 채팅 흐름을 막지 않는다. 사용자가 직접 누른 보상 행동에서만 보여준다.

- 리워드 광고: 추가 첫 쪽지권, 오늘의 추천 새로고침, 30분 프로필 부스트
- IAP 후보: 광고 제거, 추가 쪽지권 묶음, 고급 필터, 읽음 확인
- 유료화 금지: 신고, 차단, 안전 필터, 계정 삭제, 개인정보 관리

## 리스크와 대응

- 초기 밀도 부족: 지역을 좁히고 초반 획득 채널을 집중한다.
- 랜덤채팅 이미지: 수락 기반 쪽지, 안전 배지, 운영 정책을 전면에 둔다.
- 스팸/불쾌 메시지: 일일 쪽지 제한, 반복 문구 차단, 신고 누적 제한을 적용한다.
- 위치/개인정보 규제: 위치 사용 목적 고지, 최소 수집, 보관 기간 제한, 계정 삭제 절차를 출시 전 확정한다.
- 광고 피로: 채팅방 내부 광고와 강제 전면 광고는 피한다.
